# CarDD — детекция повреждений автомобиля: YOLOv8, RT-DETR

Детекция и классификация повреждений кузова автомобиля (6 классов: dent,
scratch, crack, glass shatter, lamp broken, tire flat) на данных [CarDD](https://www.kaggle.com/datasets/gabrielfcarvalho/cardd-with-yolo-annotations-images-labels)

## Результат

| Модель | test mAP50 | test mAP50-95 |
|---|---|---|
| **YOLOv8s (TTA)** | **0.7476** | **0.5976** |
| RT-DETR-L (TTA) | 0.6200 | 0.4814 |
| WBF-ансамбль (w=0.8/0.2) | 0.5818 | 0.4363 |


**WBF-ансамбль оказался хуже обеих моделей по
отдельности**

Причина в том, что у RT-DETR почти вся масса
предсказаний (98%+) имеет confidence ниже 0.1 и при взвешенном объединении
рамок через WBF эта плохо откалиброванная уверенность искажает результат
даже при небольшом весе (20%)

## Почему две принципиально разные архитектуры

**YOLOv8** — anchor-free CNN-детектор, финальный отбор рамок через NMS
(Non-Max Suppression)

**RT-DETR** — гибрид CNN-backbone + трансформер-
декодер, без NMS: сопоставление предсказаний с реальными объектами при
обучении идет через Hungarian matching, а
классификация + локализация + форма рамки считаются одним композитным
лоссом внутри самой модели

## Пайплайн проекта

```
1-yolov8         — обучение YOLOv8s, TTA, экспорт сырых предсказаний
2-rtdetr         — свой тренировочный цикл для RT-DETR-R18, TTA, экспорт
3-comparison-wbf — сравнение метрик + WBF-ансамбль на
                   сохраненных предсказаниях обеих моделей
```

Train/val/test split уже зафиксирован автором датасета

## EDA: находка, подтвердившаяся результатами моделей

Boxplot размера рамок по классам (раздел 5, ноутбук 1) показал четкое
разделение: dent/scratch/crack — типично мелкие повреждения, glass shatter/tire flat/lamp broken — крупные (20-65%), гипотеза
заключается в том, что "мелкие классы дадутся моделям труднее", и она подтвердилась, потому что 
у YOLOv8s crack худший класс (AP50 0.429),а glass shatter лучший (AP50 0.990)

## Обучение RT-DETR

**Learning rate и warmup.** Первый запуск (`lr=1e-4`, без warmup) — loss
застрял на ~9 и не двигался 18 эпох подряд, причиной можно считать одновременное
обучение уже хорошо натренированного backbone и **заново
переинициализированных** (под 6 классов вместо 80 COCO) финальных
слоев одним и тем же learning rate, поэтому резкие градиенты от случайных весов
разрушали уже полезные веса backbone. Фикс — `lr=2e-5` + 5-эпоховый линейный
warmup вместо мгновенного выхода на полный LR. После фикса
сходимость (loss 75 → 8.33 за 16 эпох), затем переобучение, поэтому обучение остановлено
вручную на 30-й эпохе

**Калибровка уверенности** 

Диагностика в процессе отладки TTA показала, что
98%+ сырых предсказаний RT-DETR имеют confidence < 0.1, то есть стандартные
пороги отсечения (0.25, обычные для YOLO) полностью обнуляли визуализацию
и вычисления, хотя реальные, верно расположенные детекции были, поэтому пришлось
использовать порог 0.05 везде, где применяется confidence threshold


## Почему WBF-ансамбль не сработал

Именно обнаруженная плохая калибровка confidence RT-DETR — вероятная
причина, почему WBF-ансамбль с YOLOv8 не дал прироста, так как взвешенное
усреднение координат рамок в WBF использует confidence как вес, и
неоткалиброванная уверенность второй модели искажает результат даже при
малой доле участия (20%)

## Ограничения
Сравнение и подбор веса ансамбля на одном фиксированном train/val/test split, без кросс-
валидации.
